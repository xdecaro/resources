# Resources by xdecaro

Joomla component for reusable allocatable resources in the xdecaro ecosystem.

## Technical identity

- Component: `com_xdecaroresources`
- Package: `pkg_xdecaroresources`
- PHP namespace: `xdecaro\Component\Resources`
- Database tables: `#__xdecaroresources_*`
- Current prerelease line: `0.2.0`

The vendor namespace is intentionally lowercase: `xdecaro`.

Version 0.2.0 is a fresh prerelease identity baseline. It does not claim an in-place Joomla upgrade from the experimental 0.1.0 `decaroresources` identity.

Resources owns resource definitions, capacity and availability-oriented metadata for things such as rooms, fields, equipment resources or services. It integrates with Core by xdecaro for shared infrastructure and public cross-product references. Inventory stock, bookings and event/course workflows remain in their owning components.
